# Curated websites, APIs and pages that publish free proxy lists (many languages).
#
# format: <hint> <url> [pages=<first>..<last>] [step=<n>]
#   hint    http | socks4 | socks5 | socks | mixed   (protocol of entries that do not say)
#   pages   the URL contains {page} (1,2,3...) and/or {offset} ((page-1)*step); pages are
#           fetched in order and the walk stops at the first page that adds nothing new.
#
# Provenance
#   [verified] fetched or confirmed alive on 2026-10-07 while preparing this list
#   all other entries come from the source lists of actively maintained community scrapers
#   (Skillter/ProxyGather, jhao104/proxy_pool, Python3WebSpider/ProxyPool,
#   bluet/proxybroker2, monosans/proxy-scraper-checker). Free sites come and go: every
#   source is health-tracked, a source that keeps failing is skipped with exponential
#   back-off (see src/scraper.py), so dead entries cost almost nothing.
